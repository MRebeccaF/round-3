Next Greater Signal

Intermediate · O(n)

Given an array of drone altitudes, return the next greater value to the right for each item. If none exists, return -1. A quadratic scan overloads the deck; use a monotonic stack and finish in linear time.

  • Time O(n)
  • Space O(n)
  • Return values, not indices
  • Empty input is valid
[4, 5, 2, 25]
→ [5, 25, 25, -1]
[13, 7, 6, 12]
→ [-1, 12, 12, -1]
